# Gleam v1.49.1 security audit

## Scope

Diff: `503424c..cb7e37c`. The release adds a private vulnerability report form, `.github/VULNERABILITY_REPORT.yml`, which GitHub enforces on the site and the API. Its Severity offers only Medium, High and Critical, and it requires the rubric answers, a fix location, a failing test and details. The scan skill writes advisory drafts in the form's sections, and `pnpm scan finish` checks them against it.

Surface paths changed, all tier 5:

- `.github/VULNERABILITY_REPORT.yml` (new): the report form above. It holds no code and changes no workflow.
- `apps/extension/package.json`, `apps/mobile/package.json`: the version only.

Run: `pnpm vitest run`, tsc on all twelve projects, eslint, `pnpm deps:check`, `pnpm wxt:build`, `pnpm check:bundles`, `pnpm mobile:build`, `pnpm test:smoke`.
